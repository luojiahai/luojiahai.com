# 8 · After Landing and Taxi to Gate

Runway vacated, stopped on the taxiway, to the gate.

## After Landing

Tower has been told the runway is vacated. Flaps and ground spoilers are still
out. Tower usually hands you to Ground, who gives the taxi instructions. Write
them down and read them back, but do not start moving until the after-landing
tasks are done unless ATC says so; online controllers expect them to take a
moment.

### After Vacating the Runway

| Control | Action | Condition |
| --- | --- | --- |
| [RMP frequency](controls.md#radio-management) | set the **Ground** frequency | as assigned by ATC, or from the airport chart |
| [APU MASTER SW](controls.md#auxiliary-power-unit-apu) pushbutton | set **ON** | – |
| [SPEED BRAKE](controls.md#flaps-and-speed-brake) lever | push down to **RET** | disarms the ground spoilers |
| [FLAPS](controls.md#flaps-and-speed-brake) lever | retract to **0** | – |
| [APU START](controls.md#auxiliary-power-unit-apu) pushbutton | set **ON** | – |
| [ENG START](controls.md#engine-start) selector | check **NORM** | – |
| [ENG ANTI ICE](controls.md#anti-ice) pushbuttons | set **OFF** | if no longer required |
| [WING ANTI ICE](controls.md#anti-ice) pushbutton | set **OFF** | if no longer required |

> [!NOTE]
> The APU keeps electrical power and air conditioning going once the engines are
> shut down at the gate.

## Taxi to Gate

After-landing tasks done, taxi instructions from Ground. Follow them on
the charts; the taxi technique is the same as on departure, see the taxi section
of [4 · Engine Start and Taxi](4-engine-start-and-taxi.md).

Request taxi to the gate,
[ATC Communications › Ground, taxi to stand](../shared/atc-communications.md#7--ground-taxi-to-stand).

> [!NOTE]
> Not every taxiway is approved for the A380. Use only the approved ones, from
> the airport's A380 taxi chart.

### Crossing a Runway

Never cross without an explicit clearance and a read back.

| Control | Action | Condition |
| --- | --- | --- |
| ATC | obtain the **crossing clearance** | read it back |
| Left and right | look out and **check visually clear** | before entering |
| [LAND](controls.md#exterior-lighting) switch | set **ON** | while crossing |
| [STROBE](controls.md#exterior-lighting) switch | set **ON** | while crossing |
| [STROBE](controls.md#exterior-lighting) switch | set back **OFF** | on the taxiway beyond |
| [LAND](controls.md#exterior-lighting) switch | set back **OFF** | on the taxiway beyond |
| ATC | report **clear of the runway** | if required |

### Turning into the Gate

| Control | Action | Condition |
| --- | --- | --- |
| [NOSE](controls.md#exterior-lighting) switch | set **OFF** | if the apron is lit well enough |
| [RWY TURN OFF](controls.md#exterior-lighting) switch | set **OFF** | so as not to blind the ground crew |
