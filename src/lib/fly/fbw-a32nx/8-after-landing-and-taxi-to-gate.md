# 8 · After Landing and Taxi to Gate

Runway vacated, stopped on the taxiway, to the gate.

## After Landing

Tower hands you to Ground, who gives the taxi instructions. Write them down and
read them back, but do not start moving until the after-landing flow is done —
online controllers expect it to take a moment. Flaps and ground spoilers are
still out at this point.

| Control | Action | Condition |
| --- | --- | --- |
| [RMP frequency](controls.md#radio-management) | set the **Ground** frequency | from ATC or the airport chart |
| [SPEED BRAKE](controls.md#flaps-and-speed-brake) lever | push down to **RET** | disarms the ground spoilers |
| [ENG MODE](controls.md#engine) selector | set **NORM** | if it was left at **IGN/START** |
| [FLAPS](controls.md#flaps-and-speed-brake) lever | set **0** | – |
| [TCAS mode](controls.md#atc-and-tcas) selector | set **STBY** | – |
| [WX RADAR MODE](controls.md#radar) selector | set **OFF** | – |
| [PWS](controls.md#radar) switch | set **OFF** | – |
| [APU MASTER SW](controls.md#auxiliary-power-unit-apu) pushbutton | set **ON** | – |
| [APU START](controls.md#auxiliary-power-unit-apu) pushbutton | set **ON** | – |
| [ENG ANTI ICE](controls.md#anti-ice) pushbutton | set **OFF** | if no longer required |
| [WING ANTI ICE](controls.md#anti-ice) pushbutton | set **OFF** | if no longer required |
| [NOSE](controls.md#exterior-lighting) switch | set **TAXI** | – |
| [RWY TURN OFF](controls.md#exterior-lighting) switch | set **ON** | – |
| [STROBE](controls.md#exterior-lighting) switch | set **AUTO** | leave **ON** while still on a runway |
| [LAND L & R](controls.md#exterior-lighting) switches | **retract** or set **OFF** | – |
| [BRK FAN](controls.md#autobrake-and-gear) pushbutton | set **ON** | on a hot brakes ECAM warning |

> [!NOTE]
> flyPad: perform the **AFTER LANDING** checklist.

## Taxi to Gate

Follow the ATC taxi instructions on the charts. The taxi technique is the same
as on departure — see the taxi section of
[4 · Engine Start and Taxi](4-engine-start-and-taxi.md).

Request taxi to the gate —
[ATC Communications › Ground, taxi to stand](atc-communications.md#7--ground-taxi-to-stand).

### Crossing a Runway

Never cross without an explicit clearance and a read back.

| Control | Action | Condition |
| --- | --- | --- |
| Left and right | look out and **check visually clear** | before entering |
| [STROBE](controls.md#exterior-lighting) switch | set **ON** | while on the runway |

### Turning into the Gate

| Control | Action | Condition |
| --- | --- | --- |
| [NOSE](controls.md#exterior-lighting) switch | set **OFF** | if the apron is lit well enough |
| [RWY TURN OFF](controls.md#exterior-lighting) switch | set **OFF** | so as not to blind the ground crew |
