# 9 · Powering Down

At the gate, back to cold and dark.

## Parking at the Gate

Engines still running, APU **AVAIL** from the taxi in, **APU BLEED** still off,
lights still in the taxi configuration.

| Control | Action | Condition |
| --- | --- | --- |
| [PARK BRK](controls.md#parking-brake) handle | set **ON** | once stopped on the stand |
| [NOSE](controls.md#exterior-lighting) switch | set **OFF** | if still on from the turn in |
| [RWY TURN OFF](controls.md#exterior-lighting) switch | set **OFF** | if still on from the turn in |
| [APU BLEED](controls.md#auxiliary-power-unit-apu) pushbutton | set **ON** | before the engines are shut down |
| [ENG MASTER 1 & 2](controls.md#engine) switches | set both **OFF** | – |
| [ECAM ENG page](controls.md#system-pages) | wait for **N1 below 5 %** | on both engines |
| [SEAT BELTS](controls.md#signs) sign | set **OFF** | – |
| [BEACON](controls.md#exterior-lighting) switch | set **OFF** | – |
| [NAV & LOGO](controls.md#exterior-lighting) switch | leave **ON** | while the aircraft still has power |
| [STROBE](controls.md#exterior-lighting) switch | leave **AUTO** | – |
| [EXT PWR](controls.md#electrical) pushbutton | set **ON** | once the ground crew has connected it |

> [!NOTE]
> flyPad: perform the **PARKING** checklist.

## Disembarking Passengers and Baggage

Real life triggers most of this by itself; in the simulator you call it in.

| Control | Action | Condition |
| --- | --- | --- |
| [GROUND SERVICES](controls.md#ground) page | connect the **jetway** | flyPad, `Ctrl+0` |
| [GROUND SERVICES](controls.md#ground) page | call **baggage** | – |

> [!NOTE]
> For a turnaround, stop here: leave the APU running, refuel, and pick the
> preparation flow back up rather than securing the aircraft.

## Securing the Aircraft

Cabin empty and cleaned.

| Control | Action | Condition |
| --- | --- | --- |
| [L TK PUMPS 1 & 2](controls.md#fuel) pushbuttons | set both **OFF** | – |
| [CTR TK PUMP 1 & 2](controls.md#fuel) pushbuttons | set both **OFF** | – |
| [R TK PUMPS 1 & 2](controls.md#fuel) pushbuttons | set both **OFF** | – |
| [ADIR 1 & 2 & 3](controls.md#adirs) selectors | set all three **OFF** | – |
| [CREW SUPPLY](controls.md#oxygen) pushbutton | set **OFF** | – |
| [APU BLEED](controls.md#auxiliary-power-unit-apu) pushbutton | set **OFF** | – |
| [EMER EXIT LT](controls.md#signs) selector | set **OFF** | – |
| [NO SMOKING](controls.md#signs) sign | set **OFF** | – |
| [COCKPIT / FWD CABIN / AFT CABIN](controls.md#air-conditioning-and-pressurisation) knobs | reset to **12 o'clock** | optional, airline SOP |
| [OVHD INTEG LT](controls.md#interior-lighting) knob | reset the brightness | optional, airline SOP |
| [APU MASTER SW](controls.md#auxiliary-power-unit-apu) pushbutton | set **OFF** | – |
| [EXT PWR](controls.md#electrical) pushbutton | set **OFF** | after 2 min, once the APU flap has closed |
| [NAV & LOGO](controls.md#exterior-lighting) switch | set **OFF** | the aircraft has no power left to light |
| [BAT 1 & 2](controls.md#electrical) pushbuttons | set both **OFF** | – |

> [!NOTE]
> The APU stays **AVAIL** for a few minutes after **APU MASTER SW** goes off if
> APU bleed was in use — it needs the cool-down period. The APU flap door needs
> APU or external power to close, so wait it out before removing ground power.
