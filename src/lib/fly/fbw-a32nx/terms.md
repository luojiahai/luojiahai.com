# Terms

The procedures use the labels printed in the flight deck, which are terse by
design — `EXT PWR`, `RET`, `TA/RA`. This page expands them.

This is the tooltip vocabulary, deliberately narrow: only the positions,
settings, systems and MCDU fields the nine procedure notes actually use. The
full FlyByWire glossary lives in [abbreviations.md](abbreviations.md) and is
rendered as its own reference sheet. Keeping the two apart matters — that
glossary is airline-wide, so it reads `RET` as *return* where the speed brake
lever means *retracted*.

Control names are expanded in the [Controls Reference](controls.md); this page
covers what those controls are set *to*. The flight companion shows both inline
under each checklist row.
